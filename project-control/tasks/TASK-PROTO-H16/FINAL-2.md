# FINAL-2 — صقل تصميمي للشريط الجانبي (بموافقة المالك)

> **الحالة:** Assigned → ui-designer · Session: NEW
> **الإذن:** المالك صرّح: «القائمة الجانبية إذا وجدتَ آلية عرض وتصميم أفضل — لا مانع».
> **المرجع:** `STYLE_CONTRACT.md` (ملزم) + `STYLE_HANDOFF.md`.

## 1. الهدف (واحد)
تحسين وضوح وتناغم الشريط الجانبي **بالتوكنز فقط** — بلا إعادة هيكلة تخطيط وبلا أي تغيير في السلوك.

## 2. المشكلات المرصودة (قياس/قراءة)
```text
1. تمييز العنصر النشط يعتمد على تعبئة خضراء فقط → غير واضح في الثيم الداكن (يذوب مع اللون)
2. تباين أحجام/أوزان عناصر التنقل غير منتظم (بعض العناصر أعرض/أثقل من غيرها)
3. عنوان القسم (TENANT) وبانر المستأجر يتنافسان بصرياً مع عناصر التنقل
4. المسافات بين المجموعات غير متسقة (قبل/بعد فواصل الأقسام)
5. الشارات (counts) قد تتفاوت محاذاتها
```

## 3. المطلوب
اقترح **ونفّذ** تعديلات كلاسات فقط لتحقيق:
- عنصر نشط واضح في الثلاثة: تعبئة `bg-sidebar-active` + نص `text-sidebar-active-text` + **مؤشّر إضافي** مسموح (حد جانبي `border-s` بلون `--focus-ring` أو وزن خط أعلى — اختر واحداً وبرّره).
- تسلسل هرمي ثابت: عنوان قسم أصغر/أخفت، عنصر تنقل موحّد الحجم والوزن، شارة محاذاة ثابتة.
- إيقاع مسافات منتظم بين المجموعات (استخدم مقاسات موجودة: 2/2.5/3/4 — لا قيم جديدة).
- لا تغيير في: ترتيب العناصر، النصوص، الأيقونات المستخدمة، منطق الطيّ/التنقل، `aria-*`.

## 4. Allowed Write Targets
```text
src\components\Sidebar.tsx
```

## 5. ممنوعات
`bg-white|slate|gray|zinc|neutral|stone|#hex|dark:*` · `style={{color|background|border|fill|stroke}}` · تغيير تخطيط (grid/flex structure) · أي مكوّن آخر · أي منطق.

صفر مخالفات · لا تغيير في عدد عناصر التنقل أو نصوصها · lint+build+227 · لقطة ×3 ثيمات (Tera) تُظهر عنصراً نشطاً واضحاً وإيقاعاً متسقاً.
